## Concrete implementation

Portable static-section source compiler uses the same parser and patcher already shipped by Theme Tools. It selects a real `data-cms-section` marker or a source offset produced by `planHtmlRebuild`. It now recognizes historical `div role=region` wrappers, hoists nested donor styles, scopes normal CSS and responsive conditions per UID, isolates HTML IDs and ARIA labels, and converts each direct source-backed text, link, and media attribute into an editable setting. Mixed strong/emphasis markup is preserved rather than flattened. No original source bytes are changed.

The existing CLI adds `agentsam-theme normalize <source> --marker <id>` or `--start <offset>` with `--entry` and `--asset` options, returning a portable definition or explicit blockers. This is not a new CLI, CMS clone, or one-off generator.
